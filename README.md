# Sistema de Inscripciones RETOS 2027

Aplicación web educativa desarrollada con **Next.js (App Router)**, **JavaScript** y **Tailwind CSS** que simula el proceso de admisión e inscripción 2027 del **Instituto Tecnológico RETOS**.

> **Nota educativa:** Este sistema está diseñado para prácticas de **Testing y Aseguramiento de Calidad (QA)**. No utiliza bases de datos ni servicios externos; la sesión se simula con `sessionStorage` y la persistencia local de inscripciones con `localStorage`.
